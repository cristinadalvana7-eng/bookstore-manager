# BookStore Manager CLI

Sistema de gerenciamento de livraria desenvolvido em Node.js, TypeScript e PostgreSQL.

## Sobre o projeto

O BookStore Manager CLI é uma aplicação executada pelo terminal para gerenciamento de:

- Autores
- Livros
- Clientes
- Empréstimos
- Devoluções
- Relatórios

O projeto utiliza uma arquitetura em camadas, separando menus, controllers, services, repositories, models e acesso ao banco de dados.

## Tecnologias utilizadas

- Node.js
- TypeScript
- PostgreSQL
- `pg`
- `dotenv`
- `ts-node`

## Pré-requisitos

Antes de executar o projeto, é necessário ter instalado:

- Node.js
- PostgreSQL
- Git
